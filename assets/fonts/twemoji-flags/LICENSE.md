# Twemoji Country Flags (web admin only)

`TwemojiCountryFlags.woff2` — from the npm package `country-flag-emoji-polyfill@0.1.8` (TalkJS, MIT),
used by `src/components/ui/CountryFlag.web.tsx` so flag emoji render on Windows browsers, which have
no flag glyphs (they show the two letters instead, e.g. «SD»).

The emoji art comes from Twemoji (https://github.com/twitter/twemoji), Copyright Twitter, Inc and
other contributors, licensed under CC-BY 4.0: https://creativecommons.org/licenses/by/4.0/
